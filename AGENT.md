# Project Agent Guidelines

## GitHub and Local Synchronization

- Keep the local working folder synchronized with the GitHub repository.
- Before making changes, fetch the latest remote state and inspect the current
  branch and working tree.
- When GitHub changes affect this project, apply the corresponding changes to
  this local folder before continuing with other work.
- Do not overwrite or discard uncommitted local changes. If local changes
  conflict with incoming GitHub changes, stop and ask for guidance.
- After making a change locally, verify the resulting files and tests before
  reporting the work as complete.
- When referencing an issue, pull request, or commit as completed, confirm that
  the implementation exists in this local working folder as well as on GitHub.
